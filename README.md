# K-Puzz

A full-featured React application for playing Kjarposko puzzles.

**[Play here!](https://samuelikohn.github.io/kpuzz/)**

## About

K-Puzz ([Kjarposko puzzles](http://www.murderousmaths.co.uk/books/kjpz.htm)) are a type of logical reasoning puzzle created by [Kjartan Poskitt](https://www.kjartan.co.uk/). This website allows you to play randomly generated K-puzzles. It is not affiliated with Kjartan Poskitt or Murderous Maths in any way.

## Features

- Randomly generated puzzles, the supply is infinite!
- Variable difficulty via puzzle sizes
- Light/dark mode toggle
- Share puzzles and your results via puzzle ID or URL
